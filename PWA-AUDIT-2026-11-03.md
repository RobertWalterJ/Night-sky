# PWA audit, 2026-11-03

App: Night Sky. Published at https://robertwalterj.github.io/Night-sky/sky/ (one shared origin with Robert's other apps).

Jargon: a "service worker" is the small script that lets the app work offline. A "cache" is the phone's saved copy of files. "Manifest id" is the name Chrome uses to tell installed apps apart.

## What was checked

The nine shared-origin rules: manifest id, scope and start_url, cache cleanup, no global caches.match(), manifest never cache-first, icons, storage names, big precache, and navigation handling. Source files and the generated docs/ or site/ folder were both read.

## Findings

| Rule | Result |
|---|---|
| 1 Manifest id | OK. id is /Night-sky/sky/. Not changed. |
| 2 Scope and start_url | OK. Both are "./" inside sky/. |
| 3 Cache cleanup | OK. Only deletes caches that start with nightsky-. The check was loose (startsWith the version), so I made it exact. |
| 4 Global caches.match() | OK. Not used. |
| 5 Manifest not cache-first | OK. The worker skips the manifest. |
| 6 Icons | OK. 192, 512 and a maskable 512. The planet and ring sit well inside the safe zone. |
| 7 Storage names | OK. localStorage keys start with ns:. Caches start with nightsky-. No IndexedDB. No clash with other repos. |
| 8 Big precache | BROKEN. The whole shell (about 6 MB, models and textures) had to download in one all-or-nothing step. Fixed. |
| 9 Navigation handling | OK. The worker never writes other addresses over index.html. |
| Other | The old root page /Night-sky/index.html deletes every nightsky- cache when opened. That is only this app's own caches, so neighbours are safe. It then redirects to sky/. Left as is. |

## What I changed

In sky/sw.js: split the shell into a small core (page, scripts, styles, fonts, icons, sky data, about 1.8 MB) that must succeed, and the rest (models, textures, big data) that fills in one file at a time and may fail without blocking. Made the cleanup match exact. Bumped the cache name to nightsky-v5-41 and BUILD in sky/js/version.js to v5-41 so they stay in step.

Checks run: .github/scripts/check-modules.mjs (34 scripts, 0 failed) and the four test scripts (all passed).

## Does the phone owner need to uninstall and reinstall?

No. The manifest id and scope did not change.

## What I could not verify

I did not install it on a phone or run a browser test of offline mode. The live site was not fetched.
